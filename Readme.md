## 🔢 JavaScript Counter App

**A simple and interactive Counter App built with HTML, CSS, and JavaScript.**

This project allows users to increase, decrease, and reset a number. The counter value is also saved in Local Storage, so the number remains available even after refreshing or reopening the page.
✨ Features
- ➕ Increase the counter
- ➖ Decrease the counter
- 🔄 Reset the counter to 0
- 💾 Save the counter value using localStorage
- 🎨 Change the number color based on its value:
  >🟢 Positive number → Green
  >🔴 Negative number → Red
  >⚫ Zero → Black
- 🔄 Restore the previous value after refreshing the page
- ⚡ Instant UI updates without reloading the page
